# 설계응답스펙트럼 · 구조물 응답 계산기

KDS 41 17 00 : 2022(건축물 내진설계기준) 4.2절에 따라 설계응답스펙트럼을 생성하고,
지진 감지기가 계측한 PGA를 구조물 고유주기 위치에 찍어 설계값과 비교하는 웹 도구입니다.

빌드 도구, 서버, 외부 API가 필요 없는 단일 HTML 파일입니다.

## 기능

- **설계응답스펙트럼** — 지진구역·지반종류·재현주기·감쇠비 선택 → S_DS, S_D1, T₀, T_S 산정 및 곡선 생성
- **구조물 응답** — 구조물 명과 고유진동수(Hz)를 입력하면 T = 1/f 위치의 설계 응답 S_a(T) 표시
- **감지기 계측값 비교** — 최대 15대까지, 감지기별 계측 PGA를 점으로 표시하고 설계값 대비 비율 판정
- **대상 지진 기록** — 지진명·진앙지·발생시간을 입력하면 보고서 머리말에 표기
- **PDF 보고서** — `〈구조물명〉 응답검토` 제목 아래 조건·파라미터 / 스펙트럼 곡선 / 감지기별 응답 3단 구성의 A4 1페이지 (감지기 9대 이상이면 표가 자동으로 2단 분할)
- **데이터 내보내기** — 주기별 값 CSV 저장, 표 클립보드 복사
- 모바일·데스크톱 반응형 (1180px 이상에서 입력 패널 고정 2단 레이아웃)

## 계산 근거

| 항목 | 식 |
| --- | --- |
| 단주기 설계스펙트럼가속도 | `S_DS = S × 2.5 × Fa × 2/3` |
| 주기 1초 설계스펙트럼가속도 | `S_D1 = S × Fv × 2/3` |
| 제어주기 | `T_S = S_D1 / S_DS`, `T₀ = 0.2 T_S`, `T_L = 5초` |
| T ≤ T₀ | `Sa = S_DS (0.6T/T₀ + 0.4)` |
| T₀ ~ T_S | `Sa = S_DS` |
| T_S ~ T_L | `Sa = S_D1 / T` |
| T > T_L | `Sa = S_D1 · T_L / T²` |

- 유효지반가속도 `S = Z × 2.0` (지진구역계수 × 2400년 재현주기 위험도계수) 또는 직접 입력
- 지반증폭계수 Fa, Fv는 표 4.2-1, 4.2-2 값을 S에 대해 직선보간
- 재현주기 배율은 KDS 41 17 00 15.3.2의 성능목표별 값 사용
- 내진설계범주는 표 5.2-1, 5.2-2를 기본설계지진 기준으로 판정
- 감쇠비 5% 외의 값은 `η = √(10/(5+ξ)) ≥ 0.55` (Eurocode 8) 보정 — **KDS에는 규정이 없는 참고값**

> 감지기 입력은 계측된 PGA 단일 값입니다. 계측 파형의 실제 응답스펙트럼이 아니므로,
> 고유주기 위치에서 설계 스펙트럼가속도와 크기만 비교합니다.
> 검토용 산출물이며 실제 판단은 계측 원파형 분석과 책임구조기술자의 검토를 거쳐야 합니다.

## GitHub Pages 배포

```bash
git init
git add .
git commit -m "설계응답스펙트럼 계산기"
git branch -M main
git remote add origin https://github.com/<사용자명>/<저장소명>.git
git push -u origin main
```

저장소 **Settings → Pages → Build and deployment**에서
Source를 `Deploy from a branch`, Branch를 `main / (root)`으로 지정하면
`https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.
